# Analysis

This folder contains downstream CDCM analyses, diagnostics, and group-level summaries performed after the primary single-subject model estimation pipeline. The scripts in this folder are primarily focused on posterior summaries, diagnostic compilation, and secondary analyses used throughout the dissertation work.

## Files

- `group_analysis_CDCM.R`  
  Runs the primary CDCM group-level analysis using posterior summaries from the single-subject CDCM models.

- `group_analysis_CDCM.sh`  
  SLURM submission script for running the CDCM group-level analysis on an HPC environment.

- `group_results_CDCM.R`  
  Compiles and summarizes CDCM group-level model outputs, including posterior summaries and downstream result tables.

- `diagnostics_compilation.R`  
  Aggregates and summarizes MCMC diagnostics and model convergence measures across subjects and runs.

- `activation_ftnd_plotting.R`  
  Generates plots relating activation measures to FTND (Fagerström Test for Nicotine Dependence) scores.

- `extract_participant_metadata.py`  
  Extracts and organizes participant-level metadata used in downstream analyses.

## Subfolders

### `Results/`

Placeholder directory for compiled analysis outputs, figures, diagnostic summaries, and group-level model results generated by the scripts in this folder.
